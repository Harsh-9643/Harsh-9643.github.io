Data Analytics Project Open Source

Zomato Bangalore Restaurants Analysis — SQL & Power BI

End-to-end analysis of Bangalore restaurant data: cleaned in Pandas, stored in MySQL, queried with SQL and presented in an interactive Power BI dashboard to explore how location, price, cuisine and online ordering relate to ratings.

Records
41,190 Rows
Database
MySQL
Dashboard
Power BI
Cleaned 51,717 raw restaurant records down to 41,190 in Pandas (duplicates, nulls, “NEW” ratings, text-to-number conversion, encoding fixes).
Loaded the data into MySQL and wrote SQL queries (GROUP BY, HAVING, CASE) for location, price-range and online-order analysis.
Found that average rating rises with price (3.57 Budget to 4.13 Luxury) and that online-order restaurants are about 24% cheaper with a similar rating (3.72 vs 3.66).
Built an interactive Power BI dashboard with KPI cards, DAX measures and slicers for location, listing type and online order.
Python Pandas MySQL SQLAlchemy Power BI DAX Matplotlib Seaborn
