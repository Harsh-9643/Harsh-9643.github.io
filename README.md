## 🚀 How to Preview Locally

### Option 1: Direct File Open
Double-click **`index.html`** in Windows File Explorer to open it in Chrome, Edge, or Brave.

### Option 2: Local Python Server (Recommended)
Open PowerShell in this directory and run:
```powershell
python -m http.server 8000
```
Then visit **[http://localhost:8000](http://localhost:8000)** in your browser.

## 🌐 How to Deploy for Free (To Add to Your Resume)

### Method A: GitHub Pages (Recommended)
1. In your GitHub account ([@Harsh-9643](https://github.com/Harsh-9643)), create a new public repository named `portfolio` (or `Harsh-9643.github.io`).
2. Push all the files from this directory to the repository.
3. On GitHub, navigate to **Settings** → **Pages** → under *Branch*, select `main` (or `master`) and `/root` → Click **Save**.
4. Your live link will be:
   `https://harsh-9643.github.io/portfolio`

### Method B: Netlify Drop (30 Seconds, No Command Line)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `portfolio` folder onto the browser.
3. Your portfolio is immediately live with a free custom SSL link (e.g. `harsh-portfolio.netlify.app`).

### Method C: Render (Same service hosting LifeDrop!)
1. Log in to your Render dashboard where LifeDrop is hosted.
2. Click **New +** → **Static Site**.
3. Connect your GitHub repository `Harsh-9643/portfolio`.
4. Leave build command empty, set publish directory to `./` (or leave default), and click **Create Static Site**.
